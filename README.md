# One Emoji, One Dream Vacation

Entry for the [make.fun bounty "One Emoji, One Dream Vacation"](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) — one emoji, nothing else, standing in for the trip of your dreams.

## The entry

🗻

- Emoji: Mount Fuji — **U+1F5FB**
- Characters (Python `len`): **1**
- UTF-8 bytes: **4** (`F0 9F 97 BB`)
- Codepoints: **1** (no variation selector, no ZWJ, no extra text)

Why Fuji: a snow-capped volcano on the horizon is a whole trip in one picture — Japan in spring, an onsen town at its foot, the climb at dawn. A specific place, not a generic beach; the stranger sees it and wants the flight.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (override with `ENTRY_OUT` or `ENTRY_OUT_DIR`) and prints exactly the entry to stdout.
